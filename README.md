# Food Delivery Analysis Dashboard

## 📊 Project Overview
Analyzed 100 food delivery orders to identify delivery delays, performance gaps and improve customer satisfaction.

## 🎯 KPIs
- Total Orders: 100
- Avg Delivery Delay: 9.2 Mins
- Total Revenue: ₹49,760
- Avg Customer Rating: 2.62

## 📈 Dashboard Contains
- Area vs Avg Delay - Bar Chart
- Weather vs Avg Delay - Bar Chart
- Order Count by Area - Pie Chart
- Average of delayminutes vs timeslot - Bar Chart

## 💡 Key Insights
- Rainy weather increases delay by 40%
- Evening slot has the highest delay
- One area needs extra delivery boy support
- Late deliveries directly impact customer rating

## 🛠️ Tools Used
- Google Sheets / MS Excel
- Pivot Tables
- VLOOKUP & Functions
- Dashboard & Data Visualization
